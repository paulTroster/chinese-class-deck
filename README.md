# Chinese Class Deck

Anki deck with the vocabulary from our Chinese intensive course (*Developing Chinese: Elementary Comprehensive Course 1*), updated after class.

**Download (the latest version):**
https://github.com/paulTroster/chinese-class-deck/releases/latest/download/1-Class.apkg

## How to use
1. Install [Anki](https://apps.ankiweb.net) (desktop) or AnkiDroid / AnkiMobile.
2. Download the file above and open it (or in Anki: File → Import).
3. To update later: download again and import again. Existing cards are updated and new words added, your own learning progress is kept.

Every card is tagged with the date of the class it came from, so you can e.g. search `tag:2026-09-30` to review one day's words.
Writing practice cards (from the handwriting assignments) are in the `Chinese::Writing` subdeck.

Audio, pictures and many example sentences come from the free "HSK 1-3 – JK" shared decks on AnkiWeb.
